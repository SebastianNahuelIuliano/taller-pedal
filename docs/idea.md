# Idea del proyecto — Taller Pedal

## 1. Nombre

Taller Pedal.

## 2. Descripción

Taller Pedal es un sistema web destinado a la gestión integral de un taller mecánico de bicicletas.

La aplicación permite digitalizar el proceso de reserva de turnos, recepción de bicicletas, diagnóstico, elaboración de presupuestos y seguimiento de reparaciones.

## 3. Problema que busca resolver

Muchos talleres mecánicos de bicicletas gestionan sus turnos y reparaciones mediante mensajes, llamadas telefónicas o anotaciones manuales.

Esto puede generar:
- Superposición de turnos.
- Pérdida de información.
- Dificultades para organizar a los mecánicos.
- Falta de seguimiento de las reparaciones.
- Errores en el control de repuestos.
- Problemas de comunicación con los clientes.

## 4. Solución propuesta

Desarrollar una aplicación web centralizada que permita administrar todas las operaciones del taller.

Los clientes podrán gestionar sus turnos y consultar el estado de sus bicicletas.

Los administradores podrán organizar el trabajo diario, gestionar presupuestos y controlar el inventario.

## 5. Usuarios del sistema

### Cliente

Persona que utiliza los servicios del taller.

### Administrador

Persona responsable de gestionar el funcionamiento del taller.

### Mecánico

Persona encargada de realizar diagnósticos y reparaciones.

## 6. Alcance funcional

El sistema incluirá:

- Gestión de usuarios.
- Registro de bicicletas.
- Catálogo de servicios.
- Gestión de mecánicos.
- Reserva y cancelación de turnos.
- Control de disponibilidad.
- Gestión de reparaciones.
- Elaboración y aprobación de presupuestos.
- Administración de repuestos.
- Historial de reparaciones.

## 7. Objetivo general

Desarrollar un sistema web que permita administrar de manera organizada, segura y eficiente los turnos y las reparaciones de un taller mecánico de bicicletas.

## 8. Objetivos específicos

- Automatizar la reserva de turnos.
- Evitar superposiciones de horarios.
- Organizar la asignación de mecánicos.
- Facilitar el seguimiento de reparaciones.
- Registrar presupuestos y autorizaciones.
- Controlar el inventario de repuestos.
- Mantener un historial de las operaciones realizadas.

## 10. Resultado esperado

Una aplicación web funcional, con frontend, backend y base de datos publicados en Internet, que permita realizar operaciones reales y aplicar las reglas de negocio definidas.
