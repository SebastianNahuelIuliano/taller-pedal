
# Idea del proyecto — Taller Pedal

## 1. Nombre

Taller Pedal.

## 2. Problema

Los talleres pequeños suelen coordinar turnos, reparaciones, presupuestos y repuestos mediante mensajes, llamadas o anotaciones. Esto puede provocar turnos superpuestos, pérdida de información, falta de seguimiento y errores de inventario.

## 3. Solución

Una aplicación web que centraliza el ciclo de atención de una bicicleta: registro del cliente y su bicicleta, reserva, recepción, diagnóstico, presupuesto, aprobación, reparación y entrega.

## 4. Usuarios

- Cliente: solicita servicios y sigue sus bicicletas.
- Mecánico: diagnostica y realiza trabajos asignados.
- Administrador: configura y supervisa la operación.

## 5. Objetivo general

Desarrollar un sistema web que permita administrar de forma organizada los turnos y las reparaciones de un taller de bicicletas.

## 6. Objetivos específicos

- Digitalizar las reservas.
- Evitar superposición de turnos y asignaciones.
- Mantener información de cada bicicleta.
- Registrar diagnósticos y presupuestos.
- Exigir autorización del cliente antes de ejecutar trabajos presupuestados.
- Controlar el uso de repuestos.
- Conservar el historial de reparaciones.

## 7. Alcance

El MVP contempla autenticación, roles, bicicletas, catálogo de servicios, agenda, turnos, asignación de mecánicos, órdenes de reparación, presupuestos, inventario e historial.

No contempla pagos en línea, aplicación móvil nativa, facturación fiscal, múltiples sucursales ni integración con WhatsApp.

## 8. Resultado esperado

Una aplicación web con frontend, backend y PostgreSQL publicados en Internet, con pruebas que permitan verificar reglas de negocio reales.
