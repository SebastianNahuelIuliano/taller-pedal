
# Glosario — Taller Pedal

| Término | Definición |
|---|---|
| Cliente | Usuario que solicita servicios del taller. |
| Mecánico | Usuario que diagnostica y repara bicicletas. |
| Administrador | Usuario con permisos de gestión global. |
| Bicicleta | Bien del cliente que ingresa al taller. |
| Servicio | Trabajo ofrecido por el taller, con duración y precio de referencia. |
| Turno | Reserva de fecha y horario para atender una bicicleta. |
| Intervalo | Período comprendido entre inicio y fin del turno. |
| Disponibilidad | Intervalo en el que un mecánico puede aceptar trabajo. |
| Bloqueo | Período no disponible en la agenda. |
| Asignación | Asociación de un turno con un mecánico. |
| Recepción | Registro de ingreso físico de la bicicleta. |
| Orden de reparación | Registro operativo asociado a la recepción y reparación. |
| Diagnóstico | Evaluación del estado y fallas detectadas. |
| Presupuesto | Propuesta de trabajos y costos que se presenta al cliente. |
| Concepto | Línea de un presupuesto con descripción, cantidad y precio unitario. |
| Aprobación | Aceptación expresa del presupuesto por el cliente propietario. |
| Estado | Situación actual de un turno u orden. |
| Repuesto | Pieza o insumo utilizado en una reparación. |
| Stock | Cantidad disponible de un repuesto. |
| Movimiento de inventario | Entrada, ajuste o consumo que modifica stock. |
| Snapshot | Copia histórica de un dato al momento de una operación. |
| Transacción | Grupo de operaciones que se confirman o revierten en conjunto. |
| Concurrencia | Acceso simultáneo de más de una solicitud al mismo recurso. |
| RN | Regla de negocio. |
| HU | Historia de usuario. |
| EC | Caso límite. |
| RNF | Requisito no funcional. |
| API | Interfaz HTTP entre frontend y backend. |
| Migración | Cambio versionado del esquema de base de datos. |
| MVP | Primera versión mínima que cumple el alcance principal. |
