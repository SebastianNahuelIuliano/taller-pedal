
# Manual de usuario — Taller Pedal

**Estado:** Guía funcional prevista. Las pantallas y nombres finales se actualizarán cuando el frontend esté implementado.

## 1. Cliente

### Crear cuenta

1. Abrir la aplicación.
2. Seleccionar Registrarse.
3. Completar nombre, apellido, correo y contraseña.
4. Confirmar el registro e iniciar sesión.

### Registrar bicicleta

1. Entrar en Mi cuenta / Mis bicicletas.
2. Seleccionar Agregar bicicleta.
3. Completar marca, modelo y tipo.
4. Guardar.

### Reservar turno

1. Abrir Servicios.
2. Seleccionar un servicio activo.
3. Elegir una bicicleta propia.
4. Consultar fecha y horarios disponibles.
5. Seleccionar horario y confirmar.
6. Verificar el turno en Mis turnos.

### Cancelar turno

1. Abrir Mis turnos.
2. Seleccionar un turno confirmado.
3. Usar Cancelar si se cumple la anticipación mínima de 12 horas.
4. Si no se permite, contactar al taller.

### Aprobar presupuesto

1. Abrir Mis reparaciones.
2. Seleccionar la orden con presupuesto pendiente.
3. Revisar conceptos y total.
4. Aprobar o rechazar.

## 2. Mecánico

1. Iniciar sesión con cuenta habilitada como mecánico.
2. Consultar agenda y órdenes asignadas.
3. Registrar recepción cuando ingresa la bicicleta.
4. Cargar diagnóstico.
5. Preparar presupuesto.
6. Esperar aprobación antes de iniciar el trabajo.
7. Actualizar estados y registrar repuestos utilizados.
8. Marcar READY cuando finaliza el trabajo.

## 3. Administrador

1. Iniciar sesión con cuenta administrativa.
2. Gestionar servicios y horarios.
3. Gestionar mecánicos y bloqueos.
4. Consultar turnos y reasignar cuando corresponda.
5. Administrar inventario.
6. Supervisar órdenes y consultar historial.

## 4. Ayuda

Si una operación no está disponible, verificar rol, estado del turno/orden y reglas de anticipación. No compartir contraseñas ni tokens.
